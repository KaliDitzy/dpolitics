When implementing new reforms, the process goes as such:
Create the gui elements in `interface/dpolitics.gui`
Setup the code for menu navigation in `common/scripted_guis/dpolitics_gui.txt`
Setup the reform ideas in `common/ideas/dpolitics_ideas.txt`
Setup the names of the reforms that will appear on the popup menu buttons in `common/scripted_localisation/dpolitics_scripted_loc.txt`
Setup minimum requirements and effects in `common/scripted_effects/dpolitics_effects.txt`
Ensure that only the correct options for reform are visible in `common/scripted_guis/dpolitics_gui.txt`

Finally, add the starting ideas for nations in their history files.
